## 2. Positioning & Messaging

**Core message**  
ScreeTC delivers real-time (or near-real-time) fluid and thermal field predictions through a simple, metered API — so you stop waiting on overnight simulations.

**Proof points (honest)**  
- Metered Axis Stream tier with transparent unit pricing.  
- Path to region-isolated and private deployments.  
- Built for NVIDIA accelerated infrastructure.  
- Strong IP and NDA posture for sophisticated buyers.

**What we never claim**  
- That the software automatically finds or closes clients.  
- That it markets itself 24/7 without human involvement.  
- Safety-critical or certified performance without independent validation.

## 4. Pilot Program

Target 3–5 design partners in the first 90 days:

1. One UAV / autonomy team (Axis Stream or small Sovereign).  
2. One data-center or facility thermal team.  
3. One manufacturing or municipal logistics team.  
4. Optional: one NVIDIA Inception peer for technical feedback.

**Pilot terms (example)**  
- Fixed pilot fee or discounted Axis Stream credits.  
- Clear success criteria (latency, accuracy on agreed scenarios, integration effort).  
- NDA where required.  
- Path to paid conversion or documented feedback.

All pilots are human-managed.
